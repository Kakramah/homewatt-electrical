# HOMEWATT ELECTRICAL

موقع عربي تعريفي لخدمات الكهرباء والطاقة الشمسية والمراقبة المنزلية والأتمتة. صفحة تفاعلية مستقلة منشورة عبر GitHub Pages.

**الموقع:** https://kakramah.github.io/homewatt-electrical/

## بنية المشروع

- `index.html`: محتوى الصفحة وأقسام الخدمات والتواصل.
- `style.css`: التصميم والاستجابة للشاشات.
- `script.js`: التفاعلات.
- `images/` و`fonts/`: الصور والخطوط المستخدمة في الصفحة.

## المعاينة والتعديل

افتح `index.html` في المتصفح، أو شغّل خادماً محلياً بسيطاً من جذر المستودع:

```sh
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000/`. راجع الصفحة على الهاتف والحاسوب، وتحقق من الصور والروابط وأزرار التواصل قبل دمج أي تعديل. لا يحتوي جذر المستودع على إعداد بناء أو مدير حزم.
